# ODST Superintendent — OpenPeon Sound Pack

Superintendent-style traffic and civic announcements for your coding session.
24 clips mapped across all 6 core and all 3 extended CESP event categories.

## Install

```
peon install odst-superintendent
```

## Category map

| Category | Clips |
|---|---|
| `session.start` | Virgil in · Welcome, access granted · Caution, traveler |
| `task.acknowledge` | Proceed with caution (×2 takes) · Please walk |
| `task.complete` | Bridge toll accepted · Please collect your tickets · Keep it clean |
| `task.error` | Access denied · Wrong way · Road closed · Crime scene, proceed with caution |
| `input.required` | Change required · Yellow means yield · Authorized personnel only |
| `resource.limit` | Final notice: bill past due · Change required |
| `user.spam` | Crime doesn't pay (×2) · Warning: convicts may be hitchhikers |
| `session.end` | Virgil out · Have a pleasant trip |
| `task.progress` | Construction ahead · Pardon our dust |

## Audio

All clips are MP3, 0.8–3.6 s, under 30 KB each (568 KB total) — within the CESP
limits of 1 MB per file and 50 MB per pack.
